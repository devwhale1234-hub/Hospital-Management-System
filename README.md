# Hospital-Management-System:
Abstract :
This Hospital Management System (HMS) portal is developed using core Object-Oriented
Programming (OOP) principles to create a modular and secure digital healthcare environment. I
have implemented Encapsulation to protect sensitive patient records and financial data within
private class members, ensuring data integrity through public getters and setters. To streamline
the code, Inheritance is used to derive specialized roles like Doctor and Patient from a central
User base class, sharing common attributes such as IDs and contact details.
The project leverages Polymorphism to provide flexible functionality, such as a single
generateReport() method that adapts for clinical, administrative, or financial outputs.
Abstraction is applied to simplify the user interface, hiding complex backend processes like
appointment scheduling and database management from the end-user. Additionally, I utilized
Composition to model real-world organizational structures, allowing the Hospital class to
manage multiple Department and Inventory objects. By applying these OOP concepts, the
system ensures a scalable, maintainable, and efficient solution for modern hospital operations.
List of 8 to 10 Main Features:
1.Patient Registration (Captures patient details for uniqueness)

2.Appointment Scheduling (Manages doctor availability and books
appointments)
3.Health Records (Manages all clinical data of the patient, test , reports )
4.Billing Management (Automates billings)
5.Pharmacy integration(Medication accordingly to the clinical data of the patient)
6.Prescription generation(Allows to digitally generate the patients prescription)
7.Inventory management(Manages the medical supplies)
8.Room management(Tracks the availability and status of beds, wards etc)
9.Different portals for admin, staff and patients
10. Staff and Doctor Management(Attendance , payrolls etc)
